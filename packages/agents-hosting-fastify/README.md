# @microsoft/agents-hosting-fastify

## Overview

Fastify hosting integration for the Microsoft 365 Agents SDK for JavaScript and
TypeScript. Provides server startup, a reusable Fastify plugin, and authenticated
request handlers that connect a Fastify application to the agent runtime.
