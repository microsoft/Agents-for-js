# @microsoft/agents-activity

## Overview

Activity Protocol types, serialization, and validation for the Microsoft 365 Agents SDK
for JavaScript and TypeScript. Provides activity models and Zod-based schemas for
exchanging messages and events between agents and channels.

This package supplies shared protocol models, not an agent host or channel transport.
