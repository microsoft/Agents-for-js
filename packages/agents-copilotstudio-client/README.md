# @microsoft/agents-copilotstudio-client

## Overview

Client for connecting JavaScript and TypeScript applications to Microsoft Copilot
Studio agents through the Direct Engine Protocol. Supports starting conversations,
sending activities, and receiving streamed responses in Node.js and browser applications.

A valid access token is required to authenticate to Copilot Studio.
