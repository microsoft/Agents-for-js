# @microsoft/agents-hosting

## Overview

Core runtime for building and hosting agents with the Microsoft 365 Agents SDK for
JavaScript and TypeScript. Provides activity processing, routing, authentication,
turn context, state management, and proactive messaging, independently of a specific
web framework.
