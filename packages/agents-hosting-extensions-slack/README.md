# @microsoft/agents-hosting-extensions-slack

## Overview

Slack integration for the Microsoft 365 Agents SDK for JavaScript and TypeScript.
Provides Slack-specific message and event routing, Slack Web API access, and
streaming responses for agents using the Azure Bot Service Slack channel.
