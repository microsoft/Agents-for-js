# @microsoft/agents-hosting-storage-blob

## Overview

Azure Blob Storage persistence for agent conversation and user state in the
Microsoft 365 Agents SDK for JavaScript and TypeScript. Provides storage providers
for both the legacy `Storage` contract and the version-aware `StorageV2` contract.
Also supports storing and retrieving conversation transcripts.
