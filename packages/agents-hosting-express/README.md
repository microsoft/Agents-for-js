# @microsoft/agents-hosting-express

## Overview

Express hosting integration for the Microsoft 365 Agents SDK for JavaScript and
TypeScript. Provides server startup and authenticated request handlers that connect
an Express application to the agent runtime.

Use this package to start a new Express server or add an agent endpoint to an
existing application. Agent behavior and state are provided by the core hosting runtime.
