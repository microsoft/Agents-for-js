# @microsoft/agents-hosting-dialogs

## Overview

Multi-turn conversation management for the Microsoft 365 Agents SDK for JavaScript
and TypeScript. Provides dialogs, waterfall flows, reusable dialog components, and
input prompts with validation, including support for migrating Bot Framework dialogs.
