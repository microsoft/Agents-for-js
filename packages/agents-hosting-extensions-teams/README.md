# @microsoft/agents-hosting-extensions-teams

## Overview

Legacy Microsoft Teams integration for the Microsoft 365 Agents SDK for JavaScript
and TypeScript. Provides Teams event handling, messaging extensions, task modules,
and Teams information APIs for existing applications.

> [!WARNING]
> This package is deprecated and retained for backward compatibility. For new
> development, use [`@microsoft/agents-hosting-extensions-msteams`](../agents-hosting-extensions-msteams),
> which uses Microsoft Teams SDK models and clients.
