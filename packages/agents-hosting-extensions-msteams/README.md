# @microsoft/agents-hosting-extensions-msteams

## Overview

Microsoft Teams integration for the Microsoft 365 Agents SDK for JavaScript and
TypeScript. Provides Teams event handling, messaging extensions, task modules, and
Teams API access using Microsoft Teams SDK models and clients.

Requires Node.js 22.12 or later.
